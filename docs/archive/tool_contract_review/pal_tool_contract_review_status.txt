B. 模型可见诊断（评审附录 B 的 A1–A11）
A1  native busy：保留 inspect_shell_status 恢复入口；跟踪状态不伪称确定阻塞根因。
A2  normalization：保留实际验证原因、session/output_ref、禁止重跑提示。
    恢复测试用只写一次 marker 证明重导出不会重复执行。
A3  write_file：有界原始 exception/errno/cause 与提交不确定性、读取后重试提示。
A4  delete_path：文件系统原因、当前 digest、部分删除风险；目录拒绝 expected_sha256
    时明确文件类型规则，不再报 hex 格式误导。
A5  channel 持久化：原始原因及回滚后的实际状态进入模型正文。
A6  builtin 输出验证：详细原因与 read_tool(view=output) 恢复入口。
A7  unknown_target：有界有效目标值进入正文，无 discovery 工具也可诊断。
A8  read_tool：默认紧凑 input，output/full 可见输出 schema/完整契约。
A9  remote 包装：保留有界 cause chain 和原始连接/准备错误。
A10 remote 子进程：保存有界 stderr；启动动作不会因继承 stderr 的 daemon 永久挂起。
A11 affordance 过滤：不可达 handler hint 被过滤后重新应用声明的 fallback，权限不扩大。
共用 diagnostics 对长度、cause 深度、URI 密码与常见 token/password 字段限界/脱敏。
不公开不必要的内部协调标识，也不把 structured 无条件全部回灌。

- LSP 空结果解释进入稳定描述；pending/timed_out 保持原状态。
- usage/cost unknown 不等于零；thinking choices 为空说明支持边界。
- grep_artifact 明确大小写不敏感词匹配，regex/逐行使用 rg。

- failure reports 明确最近 16 项窗口；control 明确 resident 重启边界。
- core cache deadline 无调度时提供 unscheduled_reason。
